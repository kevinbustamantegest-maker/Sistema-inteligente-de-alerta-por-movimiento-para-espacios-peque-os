
# Sistema inteligente de alerta por movimiento

## Problema
En algunos hogares, bodegas y espacios pequeños, las personas no siempre pueden estar pendientes de lo que sucede cuando están ocupadas o ausentes. Esto puede provocar que no se detecten movimientos inesperados a tiempo.

## Solución
El sistema detectará movimiento y activará una alerta mediante luces o sonido para informar que existe actividad en el lugar.

## Objetivos
- Construir un sistema de detección de movimiento utilizando un ESP32.
- Configurar una alerta mediante luces LED y un buzzer.
- Realizar pruebas para comprobar que el sistema detecte movimientos correctamente.

## Habilidades
- Programación de Arduino o ESP32.
- Uso de sensores.
- Conexiones electrónicas.
- Resolución de problemas.

## Alcance inicial
Un sensor de movimiento conectado a un microcontrolador, luces LED y una alerta sonora.

## Restricciones
- La primera versión funcionará en un espacio pequeño de prueba.
- El sistema solo detectará movimiento y activará una alerta.
- No incluirá cámaras ni reconocimiento de personas.
